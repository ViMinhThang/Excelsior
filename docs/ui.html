Screen Components

ChatScreen src/tui/screens/ChatScreen.tsx

The main interaction surface. Composes:

  • ChatHistory — renders DisplayBlock[] with the static/live split for Ink optimization
  • ChatInput — text input using ink-text-input with message history (↑/↓ navigation)
  • CommandSuggestions — slash command autocomplete dropdown when input starts with /
  • ThinkingIndicator — animated spinner with elapsed timer during agent execution
  • Panel — tool confirmation dialog for write/edit/runCommand approvals

SettingsScreen src/tui/screens/SettingsScreen.tsx

Configuration screen for API credentials:

  • DEEPSEEK_API_KEY — required for the AI agent
  • GITHUB_TOKEN — required for PR review features

ReviewScreen src/tui/screens/ReviewScreen.tsx

Multi-mode PR review screen. Three modes:

ModeDescription
browserBrowse open PRs, select one, view its diff. Split pane: PR list on left, diff viewer on right.
reviewLive review session. Shows orchestrator output, sub-agent status rows, and tool calls as they happen.
resultsFinal synthesized PR comment. Option to post as a GitHub comment.

Shared Components

AppHeader src/tui/components/shared/AppHeader.tsx

Application title bar displayed at the top of every screen. Shows the screen name and context-sensitive information.

MarkdownRenderer src/tui/components/shared/MarkdownRenderer.tsx

Renders markdown text to Ink elements using marked for parsing and cli-highlight for syntax highlighting. Supports headings, code blocks, tables, lists, inline formatting, and links.

Panel src/tui/components/shared/Panel.tsx

Reusable bordered panel component used for tool confirmations and modal dialogs.

Chat Components

ChatHistory src/tui/components/chat/ChatHistory.tsx

Renders the full message list. Splits blocks into frozen (has isFrozen: true) and live (still streaming). Frozen blocks render inside Ink's <Static> element for zero re-render cost. Live blocks render normally using React reconciliation.

ChatInput src/tui/components/chat/ChatInput.tsx

Wraps ink-text-input with styling consistent with the Nord theme. Supports message history navigation via ↑/↓.

AgentMessage src/tui/components/chat/AgentMessage.tsx

Renders assistant messages through MarkdownRenderer for rich markdown display with syntax-highlighted code blocks.

ToolMessage src/tui/components/chat/ToolMessage.tsx

Displays tool call information: tool name, arguments, execution status (spinner/checkmark/error), and the result output. Color-coded by tool type and status.

SubAgentRow src/tui/components/review/SubAgentRow.tsx

Compact sub-agent status row showing role, status icon (running/done/error), latest output line, and elapsed time. When selected, expands to show full output.

Review Components

PRBrowser src/tui/components/review/PRBrowser.tsx

Split pane layout for browsing PRs. Left pane: scrollable PR list. Right pane: diff viewer.

DiffViewer src/tui/components/review/DiffViewer.tsx

Colorized diff display with additions (green), deletions (red), and context lines. Uses the Nord color palette for syntax highlighting.

ReviewResults src/tui/components/review/ReviewResults.tsx

Displays the final synthesized PR review. Shows severity-ranked findings with suggested fixes. Options to post as a GitHub comment or return to the browser.

Keyboard System

The useKeymap hook (16 files) implements a prioritized keybinding system:

  • Hooks register keymaps with a priority number (higher = wins)
  • Conflict resolution: sort by priority desc, then by registration timestamp desc (LIFO tie-break)
  • Only the winning registration executes for a given key combo
  • Supports enabled/disabled toggling for contextual shortcuts
  • Normalizes key combos via parseKeyCombo() into consistent string format (e.g., "ctrl+shift+up")

Screen Navigation

The NavigationContext manages a Screen[] history stack:

  • Starts with ['chat']
  • navigate(screen) pushes to history (capped at 50 entries)
  • goBack() pops the stack (minimum 1 entry)
  • Router component reads currentScreen and renders the matching screen
