Excelsior

A terminal-based AI coding assistant powered by DeepSeek V4 Flash, built with Ink (React for CLIs) and the Vercel AI SDK.

Overview

Excelsior is a TUI (Terminal User Interface) application that provides an interactive chat experience with an AI coding agent. The agent can read, write, edit files, run shell commands, and orchestrate multi-agent PR code reviews. Conversation history is persisted locally in SQLite. It supports slash commands and keyboard-driven navigation.

Runtime

Node.js ESM with TypeScript 6.0, strict mode. Built with tsx for development.

UI Framework

Ink 7 (React 19) renders a full terminal UI with composable components, keyboard bindings, and real-time streaming.

AI Engine

Vercel AI SDK 6.0 with ToolLoopAgent providing structured tool calling and streaming responses.

Model

DeepSeek V4 Flash via @ai-sdk/deepseek 2.x. Configured via DEEPSEEK_API_KEY setting.

Persistence

SQLite via better-sqlite3 12.x with WAL mode. Stores sessions, events, settings, and error logs.

Testing

Vitest 4.x with 59 tests across 7 test files covering commands, DB, streaming types, tools, and keymaps.

Quick Start

npm install         # Install dependencies
npm run dev         # Start with tsx (development)
npm run build       # Compile TypeScript
npm start           # Run compiled output
npm test            # Run test suite

Project Structure

src/
  index.ts              # Entry point — renders Ink App
  types.ts              # Shared types (StreamPart, ConfirmBus, etc.)
  agent/                # AI agent layer
    agent.ts            #  createAgent() factory
    prompt.ts           #  System prompt builder
    tools/              #  Tool implementations
      index.ts          #   Tool registry
      fs/               #   Filesystem tools (ls, view, write, edit, glob, grep)
      runCommand/       #   Shell execution tool
      gitDiff/          #   GitHub PR diff fetching
    review/             #  Multi-agent PR review
      reviewPrompt.ts   #   Orchestrator system prompt
      spawnSubAgent.ts  #   Sub-agent spawning tool
  tui/                  # Terminal UI (Ink/React)
    app.tsx             #  Root component (providers)
    theme.ts            #  Nord-inspired theme
    screens/            #  Screen components
    components/         #  Reusable UI components
    hooks/              #  React hooks (16 files)
    context/            #  Context providers (5 files)
    lib/                #  TUI-specific utilities
  lib/                  # Core framework
    runtime/            #  Event bus, sessions, orchestrator
    persistence/        #  SQLite read/write
    projection/         #  Event → Display block transforms
  db/                   # SQLite initialization
  utils/                # Utilities (octokit, execPromise, retry)
