Excelsior

A terminal-based AI coding assistant powered by DeepSeek, built with Ink (React for CLIs).

Features

💬

Interactive Chat

Converse with an AI coding assistant directly in your terminal with real-time streaming responses.

🔧

Tool Use

The agent can read, write, list files and run shell commands with user confirmation for safety.

🔍

PR Review

Browse open pull requests, orchestrate multi-agent code reviews, and post results back to GitHub.

💾

Chat Persistence

Conversation history is stored locally in SQLite, allowing you to resume conversations.

⚙️

Settings Screen

Configure API keys and GitHub tokens without leaving the TUI application.

🤖

Multi-Agent Orchestration

Spawn specialized sub-agents (Bug Hunters, Security Auditors, etc.) for comprehensive code reviews.

Quick Start

bash 
# Install dependencies
npm install

# Set up your API key (or configure in-app via /settings)
export DEEPSEEK_API_KEY="your-key-here"

# Optional: for PR review features
export GITHUB_TOKEN="your-github-token"

# Run
npm run dev

Commands

Command Description
/helpList all available commands
/clearClear chat messages from the screen
/resetDelete all conversation history from database

Tech Stack

  • AI SDK - Vercel's AI SDK for streaming and tool calls
  • DeepSeek - Model provider (deepseek-v4-flash)
  • Ink - React for CLIs
  • React 19 - UI library
  • better-sqlite3 - Local SQLite database
  • Octokit - GitHub API client
  • TypeScript - Type safety
  • Vite/Rolldown - Build tooling
  • Vitest - Testing framework
