Tools API

The AI agent has access to seven built-in tools for repository interaction and shell execution. Each tool is defined with a Zod input schema and an execution handler. Write/edit/runCommand tools optionally require user confirmation.

ls — List Directory

src/agent/tools/fs/ls.ts

ls({ directoryPath?: string })
ParameterTypeDefaultDescription
directoryPathstring"."Path to the directory to list

Returns a formatted table with columns: TYPE | NAME | SIZE (bytes) | MODIFIED. Directories show "-" for size. Handles errors gracefully per-entry.

view — Read File

src/agent/tools/fs/view.ts

view({ filePath: string, lineStart?: number, lineEnd?: number })
ParameterTypeDescription
filePathstringPath to the file to read (required)
lineStartnumber1-based starting line number (optional)
lineEndnumber1-based inclusive ending line number (optional)

Returns contents with line numbers, a file summary header, and a separator. If no range is specified, the entire file is returned.

write — Create/Overwrite File

src/agent/tools/fs/write.ts

write({ filePath: string, content: string })
ParameterTypeDescription
filePathstringDestination file path (required)
contentstringFull content to write into the file (required)

Automatically creates parent directories via fs.mkdir({ recursive: true }). Requires user confirmation when the confirmation bus has active listeners.

edit — Edit File Snippet

src/agent/tools/fs/edit.ts

edit({ filePath: string, oldText: string, newText: string })
ParameterTypeDescription
filePathstringPath to the file to edit (required)
oldTextstringExact snippet currently in the file to replace (required)
newTextstringNew text to replace it with (required)

Atomically replaces text. Fails if oldText is not found or appears multiple times. Requires user confirmation when the confirmation bus has active listeners.

glob — Find Files

src/agent/tools/fs/glob.ts

glob({ pattern: string })
ParameterTypeDescription
patternstringA glob pattern like "src/**/*.ts" or "**/package.json"

Returns matching file paths, one per line. Capped at 500 results to prevent overload.

grep — Search Files

src/agent/tools/fs/grep.ts

grep({ query: string, pathPattern?: string })
ParameterTypeDefaultDescription
querystring—Literal text or regex string to search for (case-insensitive)
pathPatternstring"**/*"Glob pattern to scope files searched

Skips node_modules, .git, dist directories and files larger than 1MB. Results capped at 100 matches.

runCommand — Execute Shell Command

src/agent/tools/runCommand/runCommand.ts

runCommand({ command: string, args: string[] })
ParameterTypeDescription
commandstringThe executable to run (e.g., "npm", "git", "node")
argsstring[]Arguments for the command

Safety Features

FeatureDetail
Dangerous command blockingBlocks patterns like rm -rf /, mkfs, dd if=, shutdown, reboot, format, diskpart, fork bombs, etc. Includes Windows-specific patterns.
Write command detectionDetects file-modifying commands (redirection, mv/cp/rm, npm install, git push, docker build, etc.) and requires user confirmation.
Output length capLimits output to 100,000 characters to prevent memory issues
TimeoutCommands are killed after 30 seconds
No shellUses spawn(command, args, { shell: false }) — no shell interpolation

spawnSubAgent — Delegate to Specialist

src/agent/review/spawnSubAgent.ts

spawnSubAgent({ role: string, instruction: string })
ParameterTypeDescription
rolestringRole name displayed in the TUI (e.g., "Bug Hunter", "Security Auditor")
instructionstringDetailed analysis task with code context for this specialist

Execution Model

  • Creates a child AgentSession with its own event stream
  • Persists events incrementally (not batched at the end) — partial output survives crashes
  • Broadcasts lifecycle events on subAgentBus for real-time TUI display
  • Emits "child-session-attached" on the parent session for traceability
  • Returns the full output text to the parent agent when done
  • Child events are stored with their own session ID in the database

gitDiff — Fetch PR Diff

src/agent/tools/gitDiff/gitDiff.ts

gitDiff({ owner: string, repo: string, pullNumber: number })
ParameterTypeDescription
ownerstringRepository owner (user or org)
repostringRepository name
pullNumbernumberPull request number

Fetches a PR diff via the GitHub @octokit/rest API with mediaType: { format: "diff" }. Returns the raw diff text for the orchestrated code review.

Tool Registry

src/agent/tools/index.ts

The createFileTools(confirmBus?) factory assembles all file tools and wires the optional confirmation bus to write, edit, and runCommand. Extra tools (spawnSubAgent, gitDiff) are injected at call sites via createAgent()'s extraTools parameter.
