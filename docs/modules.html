Module Reference

Complete reference for all modules in the src/ directory, organized by subsystem.

Infrastructure Modules

Event Bus src/lib/runtime/bus.ts

ExportTypeDescription
createBus<TEvents>()FunctionCreates a typed pub/sub event bus with on(), emit(), once(), getListenerCount()
createChannelBus<TEvents>(channel)FunctionCreates a bus that also broadcasts to the global hub for observability
observeHub(observer)FunctionSubscribe to all events across all channel buses; returns unsubscribe function
Bus<TEvents>Interface{ on, emit, once, getListenerCount }
HubEventType{ channel: string; event: string; data: unknown }

Event Types src/lib/runtime/events.ts

ExportDescription
AgentEventDataMapMaps event type names to their data payload shapes
AgentEvent<T>Interface: { id, sessionId, sequence, type, timestamp, data, parentEventId?, relatedToolCallId? }
AnyAgentEventDiscriminated union of all event types
generateEventId()Creates unique event IDs (evt_uuid)
makeEvent(sessionId, type, data, sequence, overrides?)Factory for constructing typed events

AgentSession src/lib/runtime/agentSession.ts

MemberDescription
idUnique session identifier (ses_timestamp_random)
busChannel bus ("session") for emitting typed agent events
abortControllerAbortController for cancellation
emit(type, data, overrides?)Creates and emits a frozen event; aborted sessions reject all events except session-end
cancel()Aborts the controller and prevents further emissions
getSnapshot()Returns frozen copy of all events (for useSyncExternalStore)
subscribe(cb)Registers store listener; returns unsubscribe
flushNotify()Forces an immediate notification to all store listeners (debounced by default via setTimeout(0))

SessionOrchestrator src/lib/runtime/sessionOrchestrator.ts

MethodDescription
startRun(session, config)Starts agent execution with session, messages, agent factory, and signal. Returns { events, onComplete }. Wires event listeners to collect all events.
cancel()Cancels the current session

SessionRunConfig accepts messages, createAgent: AgentFactory, optional signal and onEvent callback.

Agent Stream src/lib/runtime/agentStream.ts

ExportDescription
streamAgentResponse(agent, messages, session, signal?)Consumes ToolLoopAgent.fullStream async iterable, translates raw stream parts to typed AgentEvents, and emits them on the session bus. Wraps agent.stream() with retry logic for transient API failures.

Persistence src/lib/persistence/eventPersistence.ts

ExportDescription
persistSession(session)INSERT OR REPLACE into sessions table
persistEvents(events)Batch INSERT OR IGNORE into agent_events with transaction
persistEvent(event)Single event insert (used for incremental sub-agent persistence)
loadSessions(limit, offset)Paginated session loading, excludes child sessions
loadSessionEvents(sessionId)Loads events for a session (cache-first, falls back to DB)
getSessionCount()Count of non-child sessions
deleteAllSessions()Deletes sessions and events (optionally preserves child sessions)

Database src/db/index.ts

ExportDescription
createDb(path?)Initializes SQLite database with WAL mode and creates tables
getDb()Returns singleton DB instance (lazy initialization)
dbProxy singleton for module-level lazy imports
initDb()Eager initialization for startup
getSetting(key) / setSetting(key, value)Settings CRUD
logError(message, stack?)Error logging to error_logs table

Agent Modules

Agent Factory src/agent/agent.ts

ExportDescription
createAgent(instructions?, extraTools?, confirmBus?)Creates a ToolLoopAgent with DeepSeek model, system prompt, file tools, and optional extra tools. The instructions parameter is appended to the system prompt for sub-agent specialization.

System Prompt src/agent/prompt.ts

ExportDescription
buildSystemPrompt(platform)Returns the full system prompt with personality rules, tone scaling (LIGHT/MODERATE/INTENSIVE), response modes, file tool usage rules, and shell command safety guidelines.

Tool Registry src/agent/tools/index.ts

ExportDescription
createFileTools(confirmBus?)Returns a record of file management tools: runCommand, ls, view, write, edit, glob, grep. Write/edit/runCommand optionally require user confirmation.

Projection Modules

Event Projection src/lib/projection/projectEvents.ts

ExportDescription
createProjectionState()Initial projection state factory
reduceProjectionEvent(state, event, options?)Pure reducer: processes a single event and mutates the projection state
flushProjectionState(state, options?)Finalizes any pending assistant/tool blocks and returns DisplayBlock[]
groupEventsForDisplay(events, options?)Convenience wrapper: creates state, reduces all events, flushes
projectChildEventsToSubAgentState(events, status)Builds SubAgentDisplayState from child session events for sub-agent rows
projectEventsToAIHistory(events)Converts events to conversation format for model context memory

Display Types src/lib/projection/display.ts

TypeDescription
DisplayBlockUnion: user | assistant | tool-call | sub-agent. Each variant carries typed data and an isFrozen? flag.
SubAgentDisplayState{ status, latestLine, fullOutput, toolCalls, parts, startTime, endTime }
SubAgentPartUnion: text | tool-call — tracks sub-agent execution parts

Utility Modules

Retry src/utils/retry.ts

ExportDescription
withRetry(fn, options?)Wraps an async function with exponential backoff (3 retries, 1s/2s/4s). Only retries transient errors (429, 502, 503, 504, network errors, ECONNRESET, ETIMEDOUT).
isTransientError(error)Heuristic check for retry-eligible errors

Octokit src/utils/octokit.ts

ExportDescription
getOctokit()Returns singleton GitHub API client. Auth from DB setting or GITHUB_TOKEN env var.
getRepoInfo()Parses owner/repo from git remote get-url origin and caches result

Screen'chat' | 'settings' | 'review'

Helper functionsgetTextDelta(), getToolName(), getToolArgs(), getToolResult()

Entry Point

src/index.ts — Application entry point. Initializes the database, renders the Ink App, and registers global error handlers for uncaughtException and unhandledRejection.
