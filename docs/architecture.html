Architecture Overview

Excelsior follows a layered architecture pattern with clear separation of concerns. The application is built on three main layers: the Agent Layer for AI interactions, the TUI Layer for terminal UI, and the Data Layer for persistence.

Data Flow Architecture

The application follows a unidirectional data flow pattern with React's component tree for UI state and an event bus pattern for cross-cutting concerns like tool confirmations and sub-agent events.
